# Estructura de Datos y Algoritmos  

Este repositorio contiene ejercicios y scripts desarrollados durante la cursada de la materia **Estructura de Datos y Algoritmos**, utilizando el lenguaje de programación C.  

## 📂 Contenidos abordados  
Los programas están basados en los siguientes conceptos:  
- Resolución de problemas y algoritmos.  
- Estructuras de datos:  
  - Arreglos y clasificación de arreglos.  
  - Estructura de lista, pila, cola y árbol.  
- Algoritmos de búsqueda, ordenamiento, actualización y recorridos.  
- Recursividad.  
- Manejo de caracteres.  
- Tipos abstractos de datos.  
- Operaciones con archivos.  
- Manejo de memoria.  
- Introducción a la programación funcional.  

## ⚠️ Aviso importante  
Este repositorio refleja mi proceso de aprendizaje, por lo que algunos programas pueden no estar completamente optimizados o contener errores.  

## 🛠 Requisitos  
Para ejecutar los programas:  
1. Un compilador de C (como GCC o Clang).  
2. Un entorno de desarrollo (Visual Studio Code, Code::Blocks, etc.) o terminal.
